# HISCALE April 25, 2016 case

This case documents the LD-Chem workflow for the HISCALE April 25, 2016 trajectory ensemble associated with Beeler et al. 2026.

The main user workflow starts from preprocessed LD-Chem inputs and runs the LD-Chem ensemble. Preprocessing code is included as a reproducibility aid, but users do not need to rerun preprocessing for a basic LD-Chem run.

## Data access

Large WRF-FLEXPART and ARM observational data files are archived outside this GitHub repository.

Data archive:

```text
https://portal.nersc.gov/archive/projects/m1657/www/Beeler_etal_2026
```

This link is not yet active.

ARM observational data may require ARM Data Center access. Manual download instructions and expected filenames are documented in `DATA.md`.

## Run from preprocessed LD-Chem inputs

From this directory:

```bash
python run_case.py
```

or explicitly:

```bash
python run_case.py --run-ensemble
```

The default workflow reads preprocessed files from `model_inputs/` and writes LD-Chem outputs to `outputs/`.

To run a small test subset:

```bash
python run_case.py --run-ensemble --max-simulations 1
```

## Regenerate LD-Chem inputs

To regenerate the LD-Chem input files from archived WRF-FLEXPART and ARM inputs:

```bash
python run_case.py --preprocess-inputs
```

This step requires the external data files described in `DATA.md`.

## Optional figure post-processing

If included, paper figure post-processing can be run with:

```bash
python run_case.py --postprocess-figures
```

This step starts from LD-Chem output files generated by the ensemble run.

## Reproducibility scope

Included in GitHub:

* LD-Chem case driver,
* preprocessing and ensemble helper scripts,
* documentation,
* preprocessed LD-Chem input descriptions,
* small metadata files.

Stored externally:

* WRF output files,
* FLEXPART-WRF output files,
* ARM observational data,
* large LD-Chem ensemble outputs.

## Current status

This case scaffold is intentionally lightweight. The preprocessed inputs in `model_inputs/` allow users to run LD-Chem without rebuilding all upstream WRF-FLEXPART and ARM-derived inputs.

The legacy HISCALE example, if present under `legacy_hiscale_example/`, is retained temporarily as source material for the preprocessing workflow. It is not the public entry point for this case.
