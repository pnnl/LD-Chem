# HISCALE April 25, 2016 case

This case documents the LD-Chem workflow for the HISCALE April 25, 2016 trajectory ensemble associated with Beeler et al. 2026.

The main user workflow starts from preprocessed LD-Chem inputs and runs the LD-Chem ensemble. A small preprocessing workflow is also included to show how LD-Chem inputs can be generated from HISCALE observational data and a FLEXPART trajectory file.

## Data access

Large WRF-FLEXPART and ARM observational data files are archived outside this GitHub repository.

Data archive:

```text
https://portal.nersc.gov/archive/projects/m1657/www/Beeler_etal_2026
```

This link is not yet active.

This repository includes a small set of sample input files under:

```text
sample_inputs/HISCALE_data_0425/
```

These sample files are intended to demonstrate the preprocessing workflow for one trajectory. They are not a complete replacement for the external data archive.

## Run from preprocessed paper inputs

From this directory:

```bash
python run_case.py
```

or explicitly:

```bash
python run_case.py --run-ensemble
```

By default, this reads the preprocessed paper inputs from:

```text
model_inputs/paper_input_files/
```

and writes LD-Chem outputs to:

```text
outputs/
```

To run only one simulation as a smoke test:

```bash
python run_case.py --run-ensemble --max-simulations 1
```

## Generate inputs from sample HISCALE/FLEXPART files

To regenerate a one-trajectory LD-Chem input set from the sample HISCALE observational files and FLEXPART output:

```bash
python run_case.py --preprocess-inputs
```

This writes generated inputs to:

```text
model_inputs/generated_inputs/
```

To generate those inputs and immediately run LD-Chem on them:

```bash
python run_case.py --preprocess-inputs --run-ensemble --max-simulations 1
```

## Optional figure post-processing

If included, paper figure post-processing can be run with:

```bash
python run_case.py --postprocess-figures
```

This step starts from LD-Chem output files generated by the ensemble run.
